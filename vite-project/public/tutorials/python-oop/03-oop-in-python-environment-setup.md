# Chapter 3: OOP in Python – Environment Setup


### Prerequisites and Toolkits
Ensure you have the latest version of Python and an IDE or text editor installed. You should be familiar with basics like `for` loops, `while` loops, `if` statements, and writing functions.

### Installing Python
1. Go to the official Python website (https://www.python.org/), click on **Downloads**, and select the latest stable version.
2. Run the downloaded installer `.exe` file. Choose **Run** and click **Next** through the default prompts to finish the setup.
3. Launch the program by selecting **IDLE (Python GUI)** to start the Python shell. You can test your installation there:
   ```python
   >>> 2 + 2
   4
   >>> print("Hello World!")
   Hello World!
   ```

### Choosing an IDE
An IDE (Integrated Development Environment) is a text editor geared towards software development. It helps manage projects, write, run, and debug code:
* **PyCharm**: Highly popular cross-platform IDE (Windows, Linux, macOS). Features code completion, navigation, integrated unit testing, debugging, Git integration, and Django support.
  * Download link: https://www.jetbrains.com/pycharm/download/
  * Supported languages: Python, HTML, CSS, JavaScript, TypeScript, CoffeeScript, Cython, AngularJS, etc.
* **Komodo IDE**: A professional polyglot IDE that supports Python, PHP, Ruby, Perl, etc. Includes integrated debugger support, DOM viewer, code profiling, and interactive shells. A trimmed free version called **Komodo Edit** is also available.
  * Download link (free): https://www.activestate.com/komodo-edit
  * Download link (paid): https://www.activestate.com/komodo-ide/downloads/ide
* **Eric Python IDE**: Open-source IDE written in Python and based on the Qt GUI toolkit and Scintilla editor. It contains indents, error highlighting, and integrated Python debugging.
  * Download link: https://eric-ide.python-projects.org/eric-download.html

### Choosing a Text Editor
For smaller tasks, quick scripts, or learning, light-weight code-centric editors are ideal:
* **Atom**: Free, open-source, and hackable editor developed by GitHub. Supports Node.js plugins, Git control, and cross-platform compatibility (macOS, Linux, Windows).
  * Download link: https://atom.io/
* **Sublime Text**: Fast proprietary editor offering a free trial. Offers custom key bindings, snippets, macros, multiple selections, and auto-completion.
* **Notepad++**: Free source code editor replacing Notepad on Windows. Governed by GPL, features syntax highlighting/folding, PCRE search/replace, tabbed editing, and supports 60+ languages.
