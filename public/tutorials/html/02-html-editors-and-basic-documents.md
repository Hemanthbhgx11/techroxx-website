# Chapter 2: HTML Editors & Basic Documents

### Writing HTML Using Notepad or TextEdit
Web pages can be created and modified by using professional HTML editors like **Visual Studio Code**, **Sublime Text**, or simple text editors like Notepad (Windows) and TextEdit (Mac). However, using a professional editor makes it easier to write and manage HTML thanks to features like syntax highlighting and auto-completion.

> **Key Note:** Save your HTML file with the `.html` or `.htm` extension. Both extensions work exactly the same.

### Step 1: Open a Text Editor
Open a plain text editor of your choice and start typing HTML code directly into it.

### Step 2: Write Some HTML
Write or copy the following HTML code into your text editor:

```html
<!DOCTYPE html>
<html>
<body>

<h1>My First Heading</h1>
<p>My first paragraph.</p>

</body>
</html>
```

### Step 3: Save the HTML Page
Save the file on your computer, selecting **File** > **Save as** in the menu, naming the file `index.html` and setting the encoding to **UTF-8**.

> **Key Note:** UTF-8 is the preferred encoding for HTML files, as it covers almost all characters and symbols in the world.

### Step 4: View the HTML Page in Your Browser
Open the saved HTML file in your favorite browser by double-clicking on the file, or right-click and choose "Open with".

### Installing a Code Editor
Although Notepad works fine, most developers prefer a dedicated code editor such as Visual Studio Code, which offers:
- **Syntax highlighting** to color-code your HTML for readability
- **Auto-closing tags** to speed up writing
- **Live Server extensions** to preview changes instantly in the browser
