# Chapter 1: OOP in Python – Introduction


### What is Object Oriented Programming?
**Object Oriented** means directed towards objects. In other words, it means functionally directed towards modelling objects. This is one of the many techniques used for modelling complex systems by describing a collection of interacting objects via their data and behavior.

Python is an Object Oriented programming (OOP) language at its core, focusing on using objects and classes to design and build applications.

#### Major Pillars of Object Oriented Programming (OOP)
1. **Inheritance**: Capture hierarchical relationships for code reuse.
2. **Polymorphism**: Allows a single interface/action to exist in many forms.
3. **Abstraction**: Exposes only essential features while hiding complex internal details.
4. **Encapsulation**: Restricts direct access to data and hides unnecessary program state.

#### Object Oriented Analysis (OOA)
Object Oriented Analysis (OOA) is the process of examining a problem, system, or task and identifying the objects and interactions between them.

### Why Choose Object Oriented Programming?
OOP offers the following advantages:
* **Clear Program Structure**: Makes it easy to map real-world problems and their solutions.
* **Easy Maintenance**: Simplifies the modification and maintenance of existing code.
* **Program Modularity**: Since each object exists independently, new features can be added easily without disturbing existing ones.
* **Framework for Code Libraries**: Supplied components can be easily adapted and modified by the programmer.
* **Code Reusability**: Imparts code reusability through inheritance and sharing.

### Procedural vs. Object Oriented Programming
* **Procedural Oriented Programming (POP)**: Derived from structural programming based on the concepts of functions, procedures, or routines. It is easy to access and change data in POP since it moves freely from function to function.
* **Object Oriented Programming (OOP)**: Decomposes a problem into a number of units called objects and builds data and functions around these objects. It emphasizes data over procedures, hiding data so it cannot be accessed directly by external procedures.

#### Major Differences
* **POP**: Focused on data and functions globally; top-down approach; lacks access specifiers; data moves freely; less secure; overloading is not possible; examples include C, VB, Fortran, Pascal.
* **OOP**: Focused on object design; bottom-up approach; supports Public, Private, and Protected access specifiers; objects communicate via member functions; data is hidden and highly secure; supports function and operator overloading; examples include C++, Python, Java, C#.

### Principles of Object Oriented Programming
* **Encapsulation**: Hides unnecessary details to manage program structure. State is hidden behind well-defined boundaries (e.g. private data) to provide a clean and simple interface.
* **Inheritance (Generalization)**: Allows a hierarchical relationship between classes (e.g., 'Fruit' generalizes 'Orange'), facilitating code reuse.
* **Abstraction**: Exposes essential features while hiding low-level details. For example, a scooter driver knows that pressing the horn emits sound, but not how that sound is mechanically or electronically generated.
* **Polymorphism**: Means "many forms". An action can occur in different ways. A good example is constructor overloading in classes.

### Object-Oriented Python
Python is designed from the ground up as an OOP language. However, you are not restricted to writing classes; you can write procedural or functional scripts too. OOP adds to Python's pragmatic design philosophy and facilitates writing bigger, complex programs.
